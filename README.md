# solaegis.com (archived)

This repository is **archived**. It is the 2016–2017 Hugo Casper / Travis / GCS source for solaegis.com. Do not clone it for site work.

**Live site:** [`solaegis/ot-config`](https://github.com/solaegis/ot-config) at `apps/solaegis/` (`onepage/` landing and Quint `blog/`). Firebase Hosting target `solaegis-com` (`https://solaegis.com/`).

Deploy from the ot-config repo:

```bash
task deploy:solaegis:onepage
task deploy:solaegis:blog
```

The Travis → GCS path in this tree is dead.
